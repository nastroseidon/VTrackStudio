# Google Data Guardrails

Google Maps, Google Earth, Street View, and Google Images may be useful for search, verification, reference, and analysis where permitted by the applicable terms and licenses.

CourseForge should not directly copy Google imagery into game textures, meshes, or final simulator assets unless the license explicitly allows that use.

CourseForge should generate original simulator assets from allowed data, user input, elevation data, procedural generation, and other permitted sources. When external sources influence a package, that source usage should be tracked.

Data-source attribution and source-report tracking should be preserved in:

```text
CoursePackage/metadata/source-report.json
```

This milestone does not implement Google API integration or any automated Google data ingestion.
